## What's new in Wave 4

Wave 4 closes the "what does a real human do with private payments" loop. Three new public link shapes, one fully-encrypted escrow, one viral share artifact, and a self-owned gas wallet so users no longer need an extension or our paymaster.

### #244 Magic Claim Links

`/claim/:chainId/:linkId#mode:secret`. Send any amount via a link. Three modes: **Bearer** (anyone with the link), **EmailBound** (only the email owner), **AddressBound** (only the named wallet). Recipient lands on a public page, claims with one click. Refund after 365-day max expiry.

FHE primitive: `FHE.eq` on the email digest for EmailBound mode.
Deployed: Eth Sepolia `0x9E2189149deec5e78cB2976d8DF64CAec40B12Be`, Base Sepolia `0x2eD78815299C2B1F2cBd2313CF763B56A0654665`.

### #254 Storefront + Sealed-Bid Auction

`/shop/:chainId/:listingId`. Sell a product with one of three modes: **FixedPrice** (encrypted price, buyer matches), **Auction** (sealed-bid, max wins), **PayWhatYouWant** (buyer names the amount).

Sealed-bid auctions are the headline FHE feature. Bids stay encrypted end-to-end. At close, the contract runs an FHE-tournament over the bid array using `FHE.gt` + `FHE.select` to pick the encrypted winner index, then `revealWinner(plaintext, signature)` lands the Threshold Network verdict. No bidder ever learns another's bid; only the winner's address surfaces publicly.

FHE primitives: `FHE.eq` (fixed-price match), `FHE.gt` + `FHE.select` (auction tournament), `FHE.gte` (Wave 4 §1.14 A8 min-bid gate).
Deployed: Eth Sepolia `0x786C85880e0FCF123D726600D9784ee88B84695b`, Base Sepolia `0xeA8a38f25ECF9Cc8C9240aafb35b561D14Dfd419`.

### #257 Encrypted Crowdfunding

`/fund/:chainId/:campaignId`. Privately-funded campaigns. Goal AND individual contributions are encrypted. After deadline, the contract computes `FHE.gte(raised, goal)` and publishes only the verdict (true/false). On success the creator pulls; on failure each contributor refunds independently.

FHE primitives: `FHE.gte` (verdict), `FHE.gt` (Wave 4 §1.14 A4 zero-goal grief guard), `FHE.add` (running raised total).
Deployed: Eth Sepolia `0x383B58973f7e8DC3E47D1C2f55393E2ac48b24e1`, Base Sepolia `0x0F21705575e2CC83dC410AE2af6973B150a4183C`.

### #249 Encrypted Escrow (fully encrypted, no plaintext amount)

Previous escrow stored a plaintext amount on-chain for indexing. Wave 4 ships `EncryptedEscrow.sol` with the amount encrypted from create through release/refund. No plaintext lookup, no leak via events. Dispute path routes to optional arbiter; no-arbiter dispute reverts cleanly (§1.2 audit fix).

FHE primitives: `FHE.allowTransient` (move ciphertext between contract + vault), `FHE.allow` (per-role decrypt gates for depositor/beneficiary/arbiter).
Deployed: Eth Sepolia `0x4253163CfCd0cf9885333E0a7B7476d61F010feC`, Base Sepolia `0x6414742D2da28eCEf06D79b82F406B6b8ab3e421`.

### §1.12 Income-Proof Viral Artifact

`/v/:proofId` is the crawler-friendly share URL. Twitter, Slack, Discord, and other unfurlers see a dynamic 1200×630 PNG generated by `@vercel/og` with the verdict pill (`Verified ✓` / `Not verified ✗` / `Pending ⏳`), the threshold ("Income ≥ $50,000"), and the FHE-explainer tagline. Real browsers bounce to the SPA at `/verify/:proofId`. Per-proof OG image generation reads the actual on-chain `PaymentReceipts.getProof` so the unfurl matches the truth.

A user creates a proof in two clicks (Proofs screen), auto-publish defaults ON so the share link is "Verified" instantly. The unfurl is the artifact you can paste into a job application, a DAO governance forum, a creator-marketplace bio.

### §1.13 Self-Owned Gas Wallet

Until now, every passkey UserOp routed through BlankPaymaster (we pay gas). When the paymaster runs dry, users are stuck. Wave 4 ships a UUPS upgrade on `BlankAccount.sol` so the smart account `receive()` auto-deposits incoming ETH into the EntryPoint as gas credit. Users can deposit ETH **from anywhere** (exchange withdrawal, hardware wallet, primary EOA) and the contract converts it. The `useUnifiedWrite` hook then automatically routes UserOps via self-pay (`paymasterAndData = "0x"`) when the deposit covers gas. Explicit caller overrides still win.

The frontend exposes a Gas wallet panel on the SmartWallet screen with: Copy address CTA, live `entryPoint.balanceOf` per chain, idle-balance display, "Self-paying mode active" badge, and a self-upgrade prompt that fires when the proxy's EIP-1967 impl slot doesn't match the deployed gas-wallet impl.

### Wave 4 hardening

A 12-item sprint week (§1.1-§1.12 in `WAVE4.md`) plus a parallel §3.x hooks-debt sprint plus a §1.14 audit refresh closed audit findings end-to-end:

- §1.1 e2e-test-wallet.json gitignored.
- §1.2 EncryptedEscrow no-arbiter dispute reverts (was permanent fund lock).
- §1.4 Storefront auction FHE-tournament + `revealWinner` (prior heuristic picked last bid, not highest).
- §1.5 ClaimLinks `MAX_EXPIRY_SECONDS = 365 days` cap (prior unbounded expiry enabled fund-then-grief).
- §1.6 useInheritance.finalizeClaim migration off the throwing stub.
- §1.7 `extractEventId` returns null on miss (prior silent zero produced wrong shareable URLs).
- §1.13 Gas wallet (see above).
- §1.14 A4 + A7 + A8 contract security upgrades (zero-goal grief, bid-spam DoS cap, below-min bid FHE.select gate).
